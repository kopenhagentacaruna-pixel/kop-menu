# Etiquetas Kopenhagen Tacaruna

Pasta pronta para publicar no GitHub Pages.

## Como publicar

1. Envie todo o conteudo desta pasta `etiquetas` para o repositorio do GitHub.
2. No GitHub, abra `Settings` > `Pages`.
3. Em `Build and deployment`, selecione `Deploy from a branch`.
4. Escolha a branch principal e a pasta `/root`.
5. Salve e aguarde o link do GitHub Pages.
